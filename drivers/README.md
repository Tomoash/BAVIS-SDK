# Community drivers / Drivery komunity

Drivers contributed to the public BAVIS catalogue. Each driver is a workspace `drivers/<name>/` with `bavis_drv_<name>/` and
`tests/`, exactly like the [examples](../examples/README.md). Read [CONTRIBUTING.md](../CONTRIBUTING.md) before you start.

Drivery, které komunita přispěla do veřejného katalogu BAVIS. Každý driver je pracovní složka `drivers/<název>/`
s `bavis_drv_<název>/` a `tests/`, stejně jako [příklady](../examples/README.md). Než začnete, přečtěte si
[CONTRIBUTING.md](../CONTRIBUTING.md).

## How to add a driver / Jak přidat driver

1. Wish or idea → [Discussions → Drivers](https://github.com/Tomoash/BAVIS-SDK/discussions/categories/drivers);
   you start writing → an issue *Driver or device request* (so nobody does the same work twice).
2. `bavis-sdk new <name> --dir drivers/<name>`, then `bavis-sdk test drivers/<name>` and `bavis-sdk check --strict drivers/<name>`.
3. A pull request with only `drivers/<name>/`. After review the driver is signed and published in the public catalogue.

Přání nebo nápad → [Discussions → Drivers](https://github.com/Tomoash/BAVIS-SDK/discussions/categories/drivers); když začnete
psát → issue *Driver or device request*. Pak `bavis-sdk new`, `test`, `check --strict` a pull request jen se složkou
`drivers/<název>/`. Po posouzení driver podepíšeme a zveřejníme ve veřejném katalogu.
