# Security policy

Please do not report security vulnerabilities in public issues.

Send the details to [benesl@benesl-automation.cz](mailto:benesl@benesl-automation.cz) with the subject
**"BAVIS security"**. Include the affected module or version, steps to reproduce and the possible impact.

You will receive a confirmation of receipt. Fixes for supported versions are provided free of charge, and the reporter is
credited in the release notes unless they prefer to stay anonymous.

Vulnerabilities in the BAVIS core application can be reported the same way.
